关于 CFIP · 常见问题

      
CFIP 是一个免费的在线 IP 信息查询工具，把归属地、运营商、ASN、节点归属、反向解析、DNSBL 黑名单与代理识别聚合到一页，并提供开放 JSON 接口。全部默认数据源均无需 API Key。

      

        IP 归属地准确吗？为什么和实际位置有偏差？
        
归属地由多个商业 IP 库（ipwho.is、ip-api、ip2region 离线库等）聚合得出，多数只能精确到城市级。移动网络、CGNAT 共享出口、企业专线与代理都会让 IP 注册地与使用者实际位置不一致，页面会给出多源位置对比，便于判断误差范围。

      

      

        查询会记录日志吗？
        
不记录查询日志、不建查询数据库。仅对查询结果做最长 6 小时的边缘缓存，用于降低上游数据源压力。

      

      

        支持 IPv6 吗？
        
支持 IPv6 查询。离线中文库 ip2region 仅含 IPv4，IPv6 的归属地、ASN、信誉等字段由在线数据源覆盖，功能不受影响。

      

      

        有免费 API 吗？怎么调用？
        
/api?ip=8.8.8.8 返回完整 JSON（CORS 全开，各数据源状态与耗时都在 meta 中）；/ip?ip=8.8.8.8 只返回纯文本 IP；不带 ip 参数则查询请求方自身 IP。
