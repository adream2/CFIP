关于 CFIP · 常见问题

      
CFIP 是一个免费的在线 IP 与网络诊断工具，把归属地、ASN、原生/广播判定、DNSBL 与代理识别聚合到一页，并提供连通性检测、WebRTC 泄漏、指纹、测速与开放 JSON 接口。默认数据源均无需 API Key。

      

      

        IP 归属地准确吗？为什么和实际位置有偏差？
        
归属地由多个商业 IP 库（ipwho.is、ip-api、ip2region 离线库等）聚合得出，多数只能精确到城市级。移动网络、CGNAT 共享出口、企业专线与代理都会让 IP 注册地与使用者实际位置不一致，页面会给出多源位置对比，便于判断误差范围。

      

      

        查询会记录日志吗？
        
不记录查询日志、不建查询数据库。仅对查询结果做最长 6 小时的边缘缓存，用于降低上游数据源压力。

      

      

        支持 IPv6 吗？
        
支持 IPv6 查询。离线中文库 ip2region 仅含 IPv4，IPv6 的归属地、ASN、信誉等字段由在线数据源覆盖，功能不受影响。

      

      

        什么是原生 IP / 广播 IP？
        
原生 IP 指 IP 的注册地与实际使用地一致；广播 IP 指注册在 A 国、实际在 B 国广播使用（常见于跨境机房、CDN 回源与代理池）。CFIP 以 RDAP 登记国家为权威、缺失时退回 AS 注册国家，与地理归属国家比对后给出判定，并附置信度与判定依据。

      

      

        连通性检测、WebRTC 泄漏和指纹是怎么测的？
        
连通性检测由你的浏览器直接连接 30 个目标站点（AI / 流媒体 / 社交 / 开发 / 国内），两轮取最小延迟，反映的是你的真实网络而不是服务器出口；WebRTC 泄漏通过 STUN 收集 ICE candidate，判断是否绕过代理暴露公网 IP、是否泄漏内网地址；指纹采集 Canvas / WebGL / 音频 / 字体等本地特征后哈希，全部在浏览器内完成，不上传任何数据。

      

      

        有免费 API 吗？怎么调用？
        
/api?ip=8.8.8.8 返回完整 JSON（CORS 全开，各数据源状态与耗时都在 meta 中）；/ip?ip=8.8.8.8 只返回纯文本 IP；不带 ip 参数则查询请求方自身 IP。
